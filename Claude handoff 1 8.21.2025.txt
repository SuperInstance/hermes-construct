Project Overview
ActiveLog.ai is a modular, AI-integrated data management ecosystem with local-first storage and selective cloud sync. The system learns from user behavior to become a better data curator over time, eventually enabling users to generate full applications from their curated data.

Technical Decisions Made
Architecture Patterns

Microservices: Each capability as independent service
Event-driven: NATS for service communication
API-first: All features exposed via REST APIs
Local-first: Default to offline storage, selective sync
Multi-tenant ready: Database schema supports tenant isolation

Technology Stack

Backend: Python/FastAPI for all services
Database: PostgreSQL with pgvector for embeddings
Storage: MinIO (S3-compatible) for files
Cache: Redis for session/cache
Search: Elasticsearch for full-text search
Messaging: NATS for event streaming
Container: Docker Compose for orchestration

Key Design Decisions

No Lambda Stack: Using containerized ML instead for cloud compatibility
Port 8088 for Gateway: Moved from 8080 due to Tomcat conflict
WSL2 over VirtualBox: Better performance, native Docker support
No GPU in dev: VirtualBox doesn't support GPU passthrough; GPU reserved for production

Sync States Design
Local-only [L]: File exists only locally
Cloud-only [C]: File exists only in cloud  
Synced [S]: File synced between local/cloud
Conflict [!]: Versions differ
Pending [⏳]: Awaiting sync
