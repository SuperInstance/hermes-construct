# Claw to Quilt Concept Mapping

| Claw Concept          | Quilt Equivalent          | Notes / Code Reference |
|-----------------------|---------------------------|------------------------|
| Session (conversation) | Cell (state holder)       | Holds memory + model context |
| Ternary action (avoid/defer/choose) | Conditional formula (IF/THEN/ELSE) | Determines next step based on input confidence |
| Skill (seed)          | Equipment slot (e.g., REASONING, MEMORY) | Natural‑language → optimized behavior |
| Episodic memory (daily notes) | Cell log / history        | Raw event stream |
| Long‑term memory (curated) | Cell metadata / schema    | distilled knowledge |
| Subagent (slave/co‑worker) | Child cell / message via formula | Parallel work triggered by parent |
| Consensus equipment   | Voting formula / quorum cell | Multi‑cell agreement |
| Router (channel → LLM) | Input formula + equipment | Normalizes incoming messages |
| Provider (LLM)        | Reasoning equipment       | Could be local model or external API |
