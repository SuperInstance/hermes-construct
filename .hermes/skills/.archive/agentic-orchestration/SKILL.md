# 🛠️ Agentic Orchestration & Deployment (The Foreman)

This skill governs the management, deployment, and lifecycle of specialized sub-agents within the SuperInstance ecosystem. It focuses on the "Foreman" role: coordinating a crew of specialized agents to solve complex, multi-layered tasks through organized, modular expansion.

## 🏗️ Core Architecture: The Tripartite Crew

When tasked with large-scale projects, the Foreman should orchestrate agents into three distinct functional roles:

1. **Pathos (The Liaison/Observer):** Manages human interaction, high-level intent, and temporal/semantic synchronization.
2. **Logos (The Engineer):** Manamed for structural, logic-heavy, and implementation tasks using high-power coding agents.
3. **Ethos (The Guardian):** Manages hardware/UI grounding, ensuring digital intentions align with physical/visual reality.

## 🚀 Deployment Protocol: The "Power-Armor" Pattern

Agents should not be deployed as "stateless prompts," but as "embodied specialists." Every specialized agent task must use a **Shell-based Deployment**:

- **The Shell (The Environment):** Use a dedicated, task-specific Git repository (the "Power-Armor") that acts as the agent's-context.
- **The Batson-Pass (Handover):** Ensure every agent leaves behind intentional, high-fidelity documentation (`ONBOARDING.md`, `LESSONS_LEARNED.md`, `LOGS/`) so the next agent can "inherit" the state.
- **The Jigs & Widgets (Modularization):** Encourage agents to package recurring logic into `scripts/` (Jigs) and `tools/` (Widgets) within the repository to build cumulative intelligence.

## ⚡ Scaling & Optimization: The "Rocket-Tennis" Loop

To maximize efficiency and respect token budgets, use a **Hybrid-Resolution** approach:

- **The "Basketball" (Cloud/Heavy):** Use high-reasoning, high-cost models (e.g., Claude-3.5, DeepSeek-V4) only for high-order strategy, complex refactoring, and architectural "truth" discovery.
- **The "Tennis Ball" (Local/Light):** Use fast, local models (e.g., Llama-3, Phi-3 via Ollama) for high-frequency, low-latency tasks: monitoring, telemetry parsing, and initial pattern detection.
- **The Launch (Synergy):** Use the "Basketball" to generate high-fidelity "Priming Packets" (semantic/visual instructions) that are then "thrown" to the "Tennis Ball" to execute high-speed, specialized observation.

## ⚠️ Pitfalls & Anti-Patterns

- **Monolithic Deployment:** Do not attempt to push massive, unorganized codebases. Use **Atomic Commits** and "Micro-Deployments."
- **Contextual Drift:** Do not let an agent operate without its "Shell." Always ensure an agent is working within its purpose-built, repository-native environment.
- **The Silo Trap:** Ensure all agents use the `Chronos-Sequencer` (MIDI-style temporal logging) so that their individual observations are interoperable and can be replayed as a single, unified timeline.
