# Search Endpoint

`website/scripts/search_images.py` defines a Flask endpoint at `/search`.

```python
@app.route("/search")
def search():
    q = request.args.get("q", "").lower()
    results = []
    for name, meta in INDEX.items():
        if q in meta.get("tags", []):
            results.append({
                "image": f"/images/{name}",
                "datetime": meta.get("datetime"),
                "tags": meta.get("tags")
            })
    return jsonify(results)
```

- **Input**: query param `q` (case‑insensitive).  
- **Output**: JSON array of matching images, each with `image` URL, `datetime`, and `tags`.  

The endpoint indexes the `.meta.json` files generated by `tag_images.py`, enabling keyword search across image metadata.
