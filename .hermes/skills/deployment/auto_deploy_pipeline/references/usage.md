# Usage Guide for the Auto‑Deploy Pipeline

## 1. Prerequisites
- Repository cloned at `~/website`.
- Virtual environment `venv4` created and activated.
- Required Python packages installed (`pip install -r requirements.txt`).
- SSH key configured for password‑less `git push` to the remote.

## 2. Setting Up the Script
1. Copy the script `auto_deploy.sh` into `~/.hermes/scripts/`.
2. Make it executable: `chmod +x ~/.hermes/scripts/auto_deploy.sh`.

## 3. Adding the Cronjob
```yaml
cronjob:
  action: create
  job_id: auto_deploy_daily
  schedule: "0 3 * * *"
  script: auto_deploy.sh
  deliver: origin
  workdir: /home/casey/.hermes/scripts
```
- This runs daily at 03:00 UTC. Adjust the schedule as needed.

## 3. Running Manually
```bash
cd ~/.hermes/scripts
./auto_deploy.sh
```
- Or use the Makefile target: `make publish` (if added).

## 4. Expected Outcome
- New PNGs are generated by `gen_hermes_sub.py`.
- Images are copied to `~/website/images/` with a timestamp.
- Changes are committed and pushed to `main`.

## 5. Troubleshooting
- **Permission denied on git push** – ensure SSH key is added to the `ssh-agent`.
- **Virtualenv not activating** – verify the `source ~/venv4/bin/activate` line is present.
- **No new PNGs** – check `output/` directory for errors from `gen_hermes_sub.py`.
