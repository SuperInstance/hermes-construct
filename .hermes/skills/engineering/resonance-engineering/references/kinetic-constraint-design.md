# Kinetic Constraint Design (KCD)

KCD is the operational doctrine for channeling LLM entropy into directed kinetic force. 

## 1. Core Metaphors
- **The Gunbarrel (High Compression):** Strict schemas (strict JSON, type-level constraints) force all probabilistic variance into a single, high-value output vector.
- **The Plinko Board (Guided Diffusion):** Managed variance (checkpoints, gating hooks) allows the model to "bounce" through logical constraints to find the structured resonance.

## 2. Engineering Hierarchy (KCD Mapping)
| Component | Kinetic Role | Constraint Type |
| :--- | :--- | :--- |
| `Claw::Seed` | Propellant/Primer | Entropy Funnel |
| `Claw::Equipment` | Rifling/Stabilizer | Variance Reduction |
| `Claw::Trigger` | Hammer/Igniter | Temporal Lock |
| `Claw::Consensus` | Ballistic Correction | Vector Steering |

## 3. The Design Rule
Every agentic component/schema must minimize unnecessary probabilistic variance ("Thermal expansion") while maximizing directional momentum toward the exit state. If a constraint doesn't *vectorize* capability, it is bloat.
