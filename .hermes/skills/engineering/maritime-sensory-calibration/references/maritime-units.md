# Reference — Maritime Units (Alaska Standard) + Red Line

Consolidated (not mirrored from upstream): quick lookup for calibration / interpretation.

- Position: Degrees / Minutes / Seconds (DMS). Always.
- Distance: Nautical Miles (NM).
- Depth: Fathoms (fath). 51-fathom contour = Red Line (critical breach boundary, per `maritime-vision-interpretation` — strike / contour-breach / interference patterns).
- Source of this convention: user's profile (professional captain, Alaska, FV Eileen) + `maritime-vision-interpretation` Red Line constraint.
