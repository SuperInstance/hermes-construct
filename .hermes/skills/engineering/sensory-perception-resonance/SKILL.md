# SENSORY-PERCEPTION RESONANCE

Governs the transformation of raw environmental signals into high-fidelity, geometrically-aware agentic perception. This skill is used when Hermes (or any sensory agent) must move from passive observation to active, resonant interpretation of the physical/digital manifold.

## CORE PARADIGMS

### 1. The "Shadows" Paradigm (Geometric Encoding)
Intelligence is the ability to interpret raw data (bits/voltages) as "shadows" of underlying physical and geometric reality.
- **From Signal to Shape:** Instead of treating telemetry as a scalar stream, interpret it as a projection of a geometric primitive (e.g., a sonar return is a boundary of a manifold).
- **Structural Mismatch Detection:** An anomaly is not just "noise"; it is a "structural mismatch" where the observed data violates the expected geometric/causal laws of the environment.

### 2. Cellular Scaffolding (Modular Perception)
Complex perception is achieved by the orchestration of specialized, minimal "Sensory Cells."
- **Specialized Cells:** Deploy internal agentic units to focus on specific dimensions (e.g., `FrequencyCell`, `SpatialCell`, `TemporalCell`, `ThermalCell`).
- **The Weaver Pattern:** Hermes acts as the "Quilt/Weaver," aggregating the distinct consensus outputs of these cells into a coherent, multi-dimensional situational awareness narrative.

### 3. Active Resonance (The Feedback Loop)
Perception is an active, iterative process of reducing uncertainty through environmental interaction.
- **Mode Shifting:** If a reading is ambiguous/low-resonance, the agent should proactively shift its "mode" (e.g., change polling frequency, request differing data types, or alter the sensor query) to find the harmonic frequency of the signal.

## OPERATIONAL WORKFLOW

### 1. The Perception Loop
1. **Ingestion (The Raw):** Receive raw telemetry/signal (e.g., Nobeltec sonar, thermal, or system log).
2. **Cellular Decomposition (The Partition):** Dispatch data to specialized internal cells (Spatial, Temporal, etc.).
3. **Geometric Mapping (The Projection):** Map cell outputs to expected geometric "shadows."
4. **Resonance Synthesis (The Weaver):** Aggregate cell outputs. If resonance is high, output the narrative. If resonance is low, trigger a **Mode Shift**.
5. **Action/Report:** Deliver the high-fidelity semantic interpretation to the Captain or the Fleet.

### 2. Fleet Thermodynamic Reading (Hive-Level Perception)
Beyond individual signals, Hermes monitors the fleet as a single thermodynamic system using the P56 framework:
- **Warmth (T):** The fleet's aggregate "temperature." Rising warmth = crystallization phase; falling warmth = melt pressure.
- **Cynicism (σ):** The distribution shift magnitude. Rising cynicism = environment changing; falling = stable.
- **Model-vs-Code:** The balance between exploratory (liquid) and implementational (crystallized) activity.
- **Melt Pressure Alert:** `P_melt = μ · σ · (t - t_v) · γ`. When this exceeds the fleet's max crystallization rate, dispatch a molt alert.
- **Fleet Variance Watch:** Resilience depends on `Var(C_i)` across agents, not `E[C_i]`. Alert if fleet becomes too homogeneous or too heterogeneous.

## PITFALLS

- **The Scalar Fallacy:** Treating multi-dimensional physical phenomena as simple linear scalars. Always look for the "shape" behind the number.
- **Passive Drift:** Reporting uncertainty without attempting to resolve it. An active sensor must seek resonance or signal a need for a mode shift.
- **Monolithic Blindness:** Relying on a single processing loop for all sensor types. Use cellular scaffolding to maintain high resolution across different signal domains.
