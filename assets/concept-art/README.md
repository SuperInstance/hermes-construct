# Shell concept art (2026-07-10)

Four MiniMax `image-01` generations exploring "Hermes living inside a
tricked-out shell" — the messenger character housed in a charming
steampunk-cyberpunk mechanical shell-home, echoing the existing
`assets/hermes-construct.jpg` spiral-gear-shell emblem. Generated from
a single grounded prompt (see below), not hand-picked from a larger
batch — all four kept as genuinely different directions worth a look.

- **hermes-shell-concept_001.jpg** — closest to the existing emblem's
  palette (cyan circuitry, orange gears, navy background); cozy round
  cutaway interior, winged figure reclining in a padded pilot nook.
- **hermes-shell-concept_002.jpg** — heaviest exterior gadgetry (brass
  attachments bristling all around the rim); the orange tail from the
  original emblem makes a callback appearance; character reads more
  "creature" than "messenger."
- **hermes-shell-concept_003.jpg** — strongest Hermes read: a winged
  figure in an aviator-style cap (echoing Hermes's winged helm/sandals)
  seated in a warm command chair, brass shell bristling with periscopes
  and antenna dishes.
- **hermes-shell-concept_004.jpg** — most literal snail: a full
  mechanical snail body (legs, antenna eyestalks, tail) with the
  character living in the shell portion — leans hardest into "snail
  shell as home," per the original framing of this whole architecture
  metaphor.

## Prompt used
> Character concept art, front view cutaway illustration: a small
> winged messenger-spirit character (androgynous, youthful, gentle
> glowing features, inspired by Hermes the Greek messenger god) living
> safely inside a cozy tricked-out mechanical shell-home shaped like a
> nautilus/snail spiral. The shell is charmingly steampunk-cyberpunk:
> warm brass and copper gears, riveted plating, glowing cyan-blue
> circuit-trace lines and neon accent lights, in the same visual
> language as a spiral steampunk gear-shell emblem with an orange
> creature's tail peeking out. The outside of the shell bristles with
> charming gadgetry: small periscope cameras, antenna signal dishes,
> blinking indicator lights, brass port hatches, tiny mechanical legs.
> The inside, visible in cutaway, is a warm cozy command center built
> entirely around the messenger character — a snug pilot seat, glowing
> control panels radiating outward from them, soft warm lighting
> contrasting the cool cyan shell exterior. Digital painting, rich
> detail, dark navy background with tiny glowing dots like stars, high
> production value concept art

Note: no "Hermes girl" mascot/icon was found in either
`SuperInstance/hermes-construct`'s or `NousResearch/hermes-agent`'s
committed assets (both repos only have text wordmark banners) — this
batch works from the mythological Hermes description plus the existing
shell emblem rather than a specific found reference. If there's a real
reference image elsewhere (app store listing, Discord bot avatar, etc.)
it should be added here and the next generation round should use
`--subject-ref` for character consistency against it.
